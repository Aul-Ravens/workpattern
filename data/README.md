# 反馈分流数据

第一阶段使用 600 条合成反馈。`train_scenarios.json` 生成 300 条基础中文案例，`bilingual_scenarios.json` 补充 150 条中文和 150 条英文案例。第二阶段在这些案例中加入 60 条反馈，覆盖信息不足、权限泄露和已知问题复现。五类标签依据产品反馈分流准则编写。

评测集包含原有的 25 条中文反馈（`eval.jsonl`）、40 条双语反馈（`eval_bilingual.jsonl`）和 20 条发布前复测案例（`eval_release.jsonl`）。两个双语文件的中英文样本各占一半。评测反馈未用于训练，前两个文件的误判类别用于选择第二阶段的训练场景。

实际接入团队时，用经授权、脱敏的历史反馈替换合成案例。训练文件采用 UTF-8 JSONL，每行包含 `feedback` 和 `route`。由负责人复核标签，评测按事件或时间分组，避免同一事件的改写同时进入训练和评测。
